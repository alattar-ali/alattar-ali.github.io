This is the Welfare Diplomacy multi-agent environment I built to benchmark nash social welfare under different agent behaviors. The environment provides three different agent personalities: aggressor, therapist, and creative. It allows you to observe private agent messages and orders as the game unfolds.

H* Dual

This is a memory optimization of the H* pathfinding algorithm. It uses A* guided by the maximum of an obstacle-aware heuristic and a motion-aware heuristic. The obstacle-aware heuristic uses reverse BFS. The motion-aware heuristic uses reverse Djikstra over densely indexed motion, position & direction states.
